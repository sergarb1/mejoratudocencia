# 📥 Bandeja de ideas — Mejora tu Docencia

Escribe aquí las ideas sueltas. Cada idea se procesa con un comando:

- `/post "idea"` → post de Instagram (carrusel + story + textos listos para copiar)
- `/recurso "idea"` → recurso en `recursos.json`
- `/experiencia "idea"` → artículo en `experiencias/<slug>/`
- `/app "idea"` → miniapp nueva + `aplicaciones.json`
- `/idea "descripción"` → añadir a esta bandeja

## Formato sugerido

- **Qué**: descripción de la idea
- **Tipo**: post / recurso / experiencia / app
- **Prioridad**: alta / media / baja
