# 💡 Banco de ideas — Mejora tu Docencia

Fuente de conocimiento del pipeline. Aquí viven todas las ideas de contenido:
las que propones tú y las que propone la IA, cada una con su estado.

## Estados

- **Aprobada** → lista para generar (la has validado)
- **Propuesta IA** → generada por la IA, espera tu aprobación
- **En proceso** → se está generando ahora
- **Hecha** → ya publicada
- **Descartada** → descartada

## Formato

`- **[tipo] Título** — origen · YYYY-MM-DD — notas`

Tipos: `post` (Instagram), `recurso` (recursos.json), `experiencia` (artículo), `app` (miniapp).

## Gestión

| Comando | Acción |
|---------|--------|
| `/idea "..."` | Añade una idea tuya como **Aprobada** |
| `/propone-ideas` | La IA propone ideas nuevas como **Propuesta IA** |
| `/sugerir` | Recomienda qué generar usando este banco + calendario + contenido existente |
| `/post` `/recurso` `/experiencia` `/app` | Generan el contenido y marcan la idea como **Hecha** |
